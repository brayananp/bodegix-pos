# Módulo: settings

## Responsabilidad

Configuración de la instalación y la bodega.

## Límites del módulo

- **Incluye:** nombre de bodega, zona horaria, moneda, preferencias de UI
- **Excluye:** gestión de usuarios (futuro), multi-sede (futuro)
