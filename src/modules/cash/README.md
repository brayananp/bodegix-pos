# Módulo: cash

## Responsabilidad

Sesiones de caja: apertura, movimientos y cierre.

## Límites del módulo

- **Incluye:** CashSession, CashDeposit, CashWithdrawal, openCash, closeCash
- **Excluye:** ventas (→ `sales`), reportes (→ `reporting`)
