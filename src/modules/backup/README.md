# Módulo: backup

## Responsabilidad

Respaldo y restauración de la base de datos local.

## Límites del módulo

- **Incluye:** exportar JSON, checksum, validar estructura, restaurar, diagnóstico
- **Excluye:** almacenamiento en nube (futuro), sincronización (futuro)
